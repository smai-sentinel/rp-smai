# RP SMAI — Sentinel Coast

משחק עולם פתוח מקורי בתלת־ממד לדפדפן, עם שרת משחק משותף, נהיגה, תפקידים, בוטים וצ׳אט. נוצר עבור SMAI.

**זוהי גרסת אלפא שאפשר לשחק בה, ולא משחק בהיקף או ברמת ההפקה של GTA.** העיר והמשחק מקוריים. אין כאן קבצים, מפות, דמויות או קוד של Rockstar. הדמויות והרכב המפורט מגיעים מנכסים שמותר להפיץ, עם רישיונות וקרדיטים מצורפים.

## הפעלה מהירה

דרוש Node.js 22.12 ומעלה, דפדפן עם WebGL 2, מקלדת ועכבר.

```bash
npm install -g pnpm@11.25.0
pnpm install --frozen-lockfile
pnpm dev
```

פותחים **http://localhost:3000** ובוחרים משחק עם חברים או משחק לבד עם בוטים.

ב־macOS אפשר גם ללחוץ פעמיים על `Start RP SMAI.command` לאחר התקנת התלויות. החלון צריך להישאר פתוח בזמן המשחק. במחשב שבו נוצר הפרויקט כבר הותקנו התלויות.

לגרסת production:

```bash
pnpm build
pnpm start
```

אפשר גם `npm install`, `npm run build`, `npm start`. קובץ הנעילה המתחזק בפרויקט הוא `pnpm-lock.yaml`.

## מה כבר עובד

- עיר חוף בגודל כ־830×830 מטר: שדרות, רבי קומות עם חלונות, פארקים, דקלים, טיילת ומזח. תאורת HDR, צללים וחומרי PBR. המבנים נוצרים גאומטרית ואינם מפת voxels.
- דמות אנושית עם עור, בגדים, שלד ואנימציית הליכה, על בסיס MakeHuman/Innerscene. צבע חולצה משתנה לפי תפקיד. זו עדיין ספריית דמות אחת עם וריאציות, לא מערכת יצירת דמויות מלאה.
- רכב קונספט מפורט עם פנים ורכיבי מרכב; מכוניות תנועה וניידות קלות יותר לרינדור. שלוש וריאציות נהיגה, האצה, היגוי, בלם יד, כניסה/יציאה, נזק והתנגשות בסיסית. אין מותגי רכב מסחריים מורשים או סימולציה מלאה של מתלים.
- עד 16 שחקנים לחדר, חדרים נפרדים לפי קוד, 32 הולכי רגל, 18 מכוניות תנועה וארבע ניידות AI. אותו עולם פועל גם במצב solo.
- בנק עם כניסה וחלל פנימי, כספת שנפתחת אחרי 14 שניות, שלל של $12,500, אזעקה, רמת מבוקשות ונקודת מילוט.
- תפקיד שוטר, סירנה, מרדף בסיסי ומעצר חשוד קרוב; בית כלא ל־30 שניות, החרמת שלל וקנס.
- כוונת, מצב כיוון, ירי hitscan שמאומת בשרת, חסימת ירי דרך קירות, פגיעות, בריאות, מחסנית וטעינה. בלי דם או אפקטים גרפיים קשים.
- משלוח לטיילת, מוסך לתיקון ולצביעה, טיפול בבית חולים ומערכת כסף בסיסית.
- צ׳אט טקסט לחדר, וויס צ׳אט WebRTC עם אישור מיקרופון, לחיצה לדיבור ועוצמה לפי מרחק עד 85 מטר.
- מפה מלאה, מינימפה, סימון יעד, HUD, מצלמות גוף ראשון ושלישי, אפקטים קוליים ומצב ביצועים.

## לשחק עם חברים

**GitHub מארח את הקוד; הוא אינו מפעיל את שרת המולטיפלייר.** GitHub Pages לבדו אינו יכול להריץ את שרת Node/WebSocket הזה.

ברשת מקומית: מפעילים את השרת במחשב אחד. שאר השחקנים פותחים `http://<כתובת-המחשב-ברשת>:3000` ובוחרים אותו קוד חדר, לדוגמה `SMAI`. התנועה והצ׳אט פועלים דרך השרת. וויס צ׳אט דורש מקור מאובטח, ולכן HTTP מכתובת רשת רגילה אינו מספיק למיקרופון; localhost כן נתמך.

למשחק דרך האינטרנט יש להריץ את הפרויקט על שרת Node או Docker עם HTTPS ותמיכה ב־WebSockets. המשתתפים נכנסים לאותה כתובת ולאותו קוד חדר. המחשב המקומי אינו שרת ציבורי רק מפני שהקוד הועלה ל־GitHub.

```bash
docker build -t rp-smai .
docker run --rm -p 3000:3000 --env-file .env rp-smai
```

להגדרות שרת, העתיקו את `.env.example` אל `.env`. להפעלת Node עם הקובץ:

```bash
node --env-file=.env server/index.js
```

| משתנה | תפקיד |
| --- | --- |
| `PORT` | פורט HTTP, ברירת מחדל 3000 |
| `ROOM_PASSWORD` | סיסמת כניסה משותפת לכל החדרים, אופציונלית |
| `PUBLIC_ORIGIN` | הכתובת הציבורית המדויקת אם reverse proxy משנה את Host |
| `TURN_URL` | שרת TURN לקול ברשתות שלא מאפשרות חיבור WebRTC ישיר |
| `TURN_USERNAME`, `TURN_CREDENTIAL` | פרטי גישה לשרת TURN |

הגדרת TURN זמינה רק ללקוחות שכבר הצטרפו. לפני חשיפה לקהל רחב, מומלץ להחליף את האישורים המשותפים באישורים קצרים שנוצרים לכל חיבור. קוד חדר הוא שם לחדר ולא סיסמה. אפשר להפעיל את השרת לקבוצת חברים עם `ROOM_PASSWORD`.

## מהלך משחק ראשון

1. נכנסים כאזרח. הרכב המפורט נמצא ליד נקודת ההתחלה. E נכנס לרכב.
2. פותחים M ובוחרים בנק סנטינל. נוסעים, עוצרים ויוצאים עם E.
3. נכנסים דרך הפתח המרכזי והולכים אל הסימון בכספת. E מתחיל שוד; צריך להישאר במקום 14 שניות.
4. בורחים עם השלל לנקודת המילוט הסגולה. כשהמשטרה רחוקה, יוצאים מהרכב ולוחצים E להפקדה.
5. אפשר במקום זאת לקחת משלוח מהמפה, או להיכנס בתפקיד שוטר ולסייר.

## מבנה הפרויקט

```text
src/                  לקוח, רינדור Three.js, ממשק, מפה, אודיו ו־WebRTC
shared/world.js       המפה, חסימות ונקודות עניין משותפות
shared/simulation.js  לוגיקת משחק סמכותית, תנועה, עבודות, AI וירי
server/index.js       Express, חדרי Socket.IO, סנכרון וסיגנלינג לקול
public/models/        נכסי GLB מקומיים
public/environment/   תאורת HDR מקומית
public/licenses/      קרדיטים ורישיונות הנכסים
tests/                בדיקות לוגיקת משחק ורשת עם לקוחות אמיתיים
```

השרת מריץ סימולציה ב־30Hz ומשדר snapshots ב־15Hz. הלקוח שולח קלט, לא מיקומים או יתרות כסף. תנועה, שוד, מעצר, תחמושת וכסף מחושבים בשרת. במצב solo אותה סימולציה רצה בדפדפן. מיקום, תפקיד וכסף ברשת נשמרים בזיכרון החדר בלבד; חיבור מחדש מתחיל דמות חדשה. במצב solo נשמרת רק יתרת הכסף בדפדפן המקומי.
